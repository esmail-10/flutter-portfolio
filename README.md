# 🚀 Flutter Developer Portfolio

A professional, beautifully crafted portfolio app built with **Flutter** to showcase my projects, skills, and experience as a mobile developer.

---

## ✨ Features

- 🎨 **Modern UI Design** — Clean, premium look with smooth animations and transitions
- 📱 **Responsive Layout** — Optimized for various screen sizes
- 🖼️ **Project Showcase** — Detailed project cards with screenshots and descriptions
- 🔗 **External Links** — Direct links to GitHub, Play Store, and live demos
- 🌐 **Web Support** — Deployable as a Flutter Web app
- 🔤 **Google Fonts** — Premium typography powered by `google_fonts`

---

## 📂 Project Structure

```
lib/
├── core/           # App theme, constants, and utilities
├── data/           # Static project data and content
├── models/         # Data models (e.g., Project model)
├── screens/        # App screens
│   ├── portfolio_screen.dart       # Main portfolio home screen
│   └── project_details_screen.dart # Detailed project view
└── widgets/        # Reusable UI components
```
